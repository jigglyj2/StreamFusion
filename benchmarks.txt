# Nexmark throughput

Local smoke run: q0, 100,000 events, memory backend, mini-batching off, exactly-once
Kafka input/output. These cold end-to-end numbers include MiniCluster startup and are
proof of execution, not a stable performance baseline.

|---|---:|---:|---:|
| memory / mini-batch off | 16,234 records/s | 16,694 records/s | 1.03x |
